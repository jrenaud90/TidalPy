# TidalPy Dynamics

TidalPy's dynamics API is undergoing changes and this page will be updated once that work is complete. Until then, please see the autogenerated API documentation.

As of TidalPy v0.7.0 the dynamics functionality is split between the `TidalPy.dynamics` and `TidalPy.tides` modules. It will be refactored into a new `TidalPy.Dynamics` module (with a capital).
