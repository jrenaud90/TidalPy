# Utilities_x: Associated Legendre Functions (`legendre`)

Unnormalized associated Legendre functions `P_lm(cos theta)` with their first and second colatitude
derivatives, using the **Condon-Shortley phase** convention (the same convention as
`scipy.special.assoc_legendre_p` with `branch_cut=2`). These are the angular building blocks of the
tidal potential used by the 3D tidal stress/strain/heating pipeline.

Two evaluation paths, both returning the triple `(P_lm, dP_lm/dtheta, d2P_lm/dtheta2)`:

- **`legendre(l, m, colatitude)`** — fast precomputed closed forms for degrees `l = 2..10`. Each
  `(l, m)` is a hard-coded polynomial in `cos(theta)` and `sin(theta)` (no `std::pow`, no `1/sin theta`
  singularities in the interior), generated by `legendre/codegen/gen_legendre.py` via the Ferrers
  construction.
- **`legendre_generic(l, m, colatitude)`** — generic evaluator for any degree `l`, backed by the
  vendored `xsf` special-function library (value from `xsf::assoc_legendre_p`, derivatives from `xsf`
  dual numbers via the chain rule). It is a fallback for degrees outside the precomputed range; the
  current tidal pipeline uses only the fast table path.

All angles are in radians; colatitude `theta` in `[0, pi]`. An out-of-range order (`m < 0` or `m > l`)
returns a NaN triple.

---

## Python API

```python
from TidalPy.Utilities_x.legendre import legendre, legendre_generic
import numpy as np

theta = 1.1
p, dp_dtheta, d2p_dtheta2 = legendre(2, 1, theta)        # precomputed table (l = 2..10)
p2, _, _ = legendre_generic(11, 4, theta)                # any degree
```

| Function | Description |
|----------|-------------|
| `legendre(l, m, colatitude)` | Precomputed `(P_lm, dP/dtheta, d2P/dtheta2)` for `l = 2..10`. NaNs outside that range or for `m` out of range. |
| `legendre_generic(l, m, colatitude)` | Same triple for any `l >= 0` via `xsf`. NaNs for `m` out of range. |

Both agree with `scipy.special.assoc_legendre_p` (value + derivatives, chain-ruled to colatitude) and
with each other to ~1e-11 across all supported `(l, m)`.

## C++ API

Header-only, namespace `tidalpy`.

```cpp
#include "legendre_driver_.hpp"    // precomputed tables l = 2..10 + dispatch
#include "legendre_generic_.hpp"   // generic xsf evaluator (any degree)

tidalpy::c_LegendreValue v  = tidalpy::c_legendre(2, 1, colatitude);          // table
tidalpy::c_LegendreValue vg = tidalpy::c_legendre_generic(11, 4, colatitude); // generic
// v.p, v.dp_dtheta, v.d2p_dtheta2
```

| Symbol | Description |
|--------|-------------|
| `struct c_LegendreValue { double p, dp_dtheta, d2p_dtheta2; }` | One `P_lm(cos theta)` and its first/second colatitude derivatives (`legendre_common_.hpp`). |
| `c_LegendreValue c_legendre(int l, int m, double colatitude)` | Precomputed tables, `l = 2..10` (`legendre_driver_.hpp`). NaN triple outside the supported range or for `m` out of range. |
| `c_LegendreValue c_legendre_generic(int l, int m, double colatitude)` | Generic `xsf`-backed evaluator, any `l` (`legendre_generic_.hpp`). |
| `c_legendre_l{2..10}(int m, double cos_t, double sin_t)` | The per-degree table functions the driver dispatches to (`legendre_l{2..10}_.hpp`). |

The `l = 2` table reproduces the hand-coded forms used historically by the tidal kernel exactly
(`P_20 = ½(3cos²θ−1)`, `P_21 = −3cosθ sinθ`, `P_22 = 3sin²θ`).

---

## Where it is used

- The 3D tidal potential engine (`Tides_x`) evaluates `P_lm(cos theta)` and its derivatives at the
  colatitude of each query point to build the tidal potential and its angular derivatives per mode.
